# [スキル名（日本語）]

## 目的
[このスキルが材料を供する判断を 1 文で書く。「〜を調べる」ではなく「〜を決めるために〜を揃える」。]

## 選手コンテキスト
1. `profile.md` を読む。使う項目: [項目名を列挙]。
2. 空の項目は推測で埋めず、出力の冒頭に「profile.md 未記入: [項目]」と書く。
3. `inputs/[skill-name]/` にファイルがあれば読む（人手で起こしたメモ。出典は「本人メモ」）。

## 情報源一覧
優先順に並べる。区分は `docs/DECISIONS.md` D-4 の 4 区分（確定情報 / 報道 / 噂 / 推定）。

| 優先 | 情報源 | URL / 探し方 | 区分 | 更新される頻度 |
|---|---|---|---|---|
| 1 | [団体公式] | | 確定情報 | |
| 2 | [コミッション / 規定文書] | | 確定情報 | |
| 3 | [論文・公的データ] | | 確定情報 | |
| 4 | [記録サイト] | | 確定情報 / 推定 | |
| 5 | [報道] | | 報道 | |
| 6 | [当事者 SNS] | | 当事者発信（公式確認まで報道扱い） | |

## 収集手順
1. [profile.md から抜き出した条件で、情報源 1 から順に当たる。]
2. [各情報に取得元 URL と取得日を付けて控える。]
3. [確定情報 / 報道 / 噂 / 推定 に分ける。]
4. [選手の条件に当てはめ、判断に関係する差分だけを残す。]
5. 出力を `outputs/[skill-name]/YYYY-MM-DD-[件名].md` に保存する。

```markdown

## 報道
- [内容] — 出典: [媒体名 URL]（YYYY-MM-DD）

- [内容] — 出典: [どこで見たか]。確認方法: [何を見れば確定するか]

## 推定
- [値] — 算出元: [URL]。前提: [何を仮定した値か]

1. [判断] — 選択肢 A: [条件] / 選択肢 B: [条件]

## 鮮度
- 再確認が必要になる条件: [例: 次の計量結果が出たとき、ルール改定の告知があったとき]
```

## 更新頻度
[随時 / 週次 / 月次] — [理由。何がどの速さで変わるか。]

## 禁止事項
- 出典のない数値を書かない。
- 推測を事実の文体で書かない。
- [領域固有の禁止。医療・法律・税務の断定は該当する専門職への確認を促す文を必ず添える。]
- 固有名詞・技術用語は原語を併記する（例: 水抜き（water cut））。
