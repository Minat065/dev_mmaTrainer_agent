# <スキル名>

## 目的
このスキルが支援するトレーナーの判断を 1 文で書く。「〜を調べる」ではなく「〜を決めるために〜を出す」と書く。

## 入力
- 選手プロファイル: `profiles/<選手名>.md` を最初に読む。存在しない場合はトレーナーに作成を求め、推測で埋めない。
- 引数: `$ARGUMENTS` の解釈規則を書く（省略時の既定値を含む）。
- 参照資料: `references/` 配下のファイルがあれば列挙する。

## 手順
1. プロファイルを読み、判断に関係する項目（階級、スタイル、負傷歴、直近の試合など）を抜き出す。
2. 情報収集。各情報に取得元と取得日を記録する。
3. 事実・推論・仮説に分けて整理する。
4. 判断への接続。トレーナーが次に決めることと、その選択肢ごとの根拠を書く。

## 出力形式
```
## 結論（判断に直結する 3 行以内）
## 事実（出典付き）
- 事実 — 出典: <URL または資料名>（取得日 YYYY-MM-DD）
## 推論（事実から導いたこと。根拠となる事実を指す）
## 仮説（検証が必要なこと。検証方法を添える）
## 次に決めること
- 選択肢 A / B と、それぞれを選ぶ条件
## 鮮度
- この情報の有効期限と、再確認が必要になる条件
```

## 鮮度要件
この領域の情報が古くなる速さを宣言する（例: 対戦相手の直近成績は試合ごと、ルール改定は年次、生理学の基礎知見は数年）。宣言した期間を超えた情報には「要再確認」と付ける。

## 禁止事項
- 出典のない数値を書かない。
- 推測を事実の文体で書かない。
- 医学的判断を断定しない。負傷・減量・投薬に関わる助言は医師・栄養士への確認を促す文を必ず添える。
