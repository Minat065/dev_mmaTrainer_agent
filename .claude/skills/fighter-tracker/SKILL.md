# 選手トラッカー（fighter tracker）

## 目的
同階級とその周辺で誰が勝ち、誰が消え、誰が空いているかを週次で把握し、マッチメイクの好機（相手の欠場、ランキングの空き、団体の階級再編）を見逃さないための差分台帳を作る。
このスキルは事実の収集と差分の提示までを行い、相手の選定判断は matchmaking に渡す。

## 選手コンテキスト
1. `profile.md` を読む。使う項目: 所属団体、階級、追跡したい選手、次戦の相手、目標。
2. 引数に選手名があればその選手だけを対象にする。なければ profile.md の追跡リスト全員。追跡リストが未記入なら、所属団体の同階級ランキング上位 15 名を対象にし、その旨を出力に書く。
3. `outputs/fighter-tracker/` の直近ファイルを読み、前回の状態を把握する。初回は「前回なし」とする。

## 情報源一覧

| 優先 | 情報源 | URL / 探し方 | 区分 | 更新される頻度 |
|---|---|---|---|---|
| 1 | 団体公式（結果、契約、リリース発表、次戦発表） | UFC https://www.ufc.com/ 、ONE https://www.onefc.com/ 、RIZIN https://jp.rizinff.com/ のニュースと大会ページ | 確定情報 | 随時 |
| 2 | 戦績データベース | Sherdog https://www.sherdog.com/ 、Tapology https://www.tapology.com/ の選手ページ（結果、予定試合、計量結果） | 確定情報 | 試合ごと |
| 3 | 報道 | MMA Fighting、MMA Junkie、Sherdog、ESPN MMA、日本語は各団体公式と実名メディア（移籍、負傷、引退、契約交渉） | 報道 | 随時 |
| 4 | 選手本人・陣営の SNS | 引退表明、負傷公表、次戦の予告 | 当事者発信（団体公式の確認まで報道扱い） | 随時 |
| 5 | 匿名ソース・まとめサイト | 「○○が離脱らしい」 | 噂 | 随時 |

## 収集手順
1. 対象選手ごとに、情報源 1〜2 で前回取得日以降の次の変化を取る。試合結果（相手、方法、ラウンド）、次戦の発表（相手、日程、大会）、計量結果、契約・移籍・リリース、引退・復帰、負傷による欠場。
2. 情報源 3〜4 で、公式発表のない動き（交渉中、負傷の噂、階級変更の意向）を取り、区分を付ける。
3. 前回ファイルと比べ、変化のあった選手だけを「差分」に書く。変化のなかった選手は名前だけ列挙する。
4. 差分の中から、自分の階級と目標に関係するものを抽出する。例: ランキング上位者の欠場（空いた枚数）、同階級の新規契約、対戦候補の次戦決定（当面組めない）、相手の階級変更。
5. 判断への接続を 1〜3 点書き、matchmaking で深掘りすべき点を指す。
6. 出力を `outputs/fighter-tracker/YYYY-MM-DD.md` に保存する。

## 出力テンプレート
```markdown
# 選手トラッカー（fighter-tracker / 取得日 YYYY-MM-DD / 前回 YYYY-MM-DD）

profile.md 未記入: [なし / 項目名]
対象: [人数] 名（profile.md の追跡リスト / ランキング上位で代替）

## 結論（自分に関係する差分）
- [例: ランキング 5 位 ○○ が負傷欠場（報道）。6 月まで空く見込み]

## 差分（前回以降に変化のあった選手）
| 選手（原語） | 変化 | 区分 | 出典（日付） |
|---|---|---|---|
| | 試合結果 / 次戦発表 / 移籍 / 引退 / 負傷 / 契約 | 確定情報 / 報道 / 当事者発信 / 噂 | |

## 変化なし
[名前の列挙]

## 噂・未確認
- [内容] — 出典。確認方法: [団体公式の発表を待つ、など]

## この情報で変わり得る判断（1〜3 点）
1. [例: ○○の欠場で空いた枠に名乗りを上げるか → matchmaking で検討]

## 鮮度
- 次回実行: [日付]。大会開催直後は臨時で実行する
```

## 更新頻度
週次。スケジュール実行の対象（`docs/DECISIONS.md` D-1）。所属団体の大会が開催された翌日に臨時実行する。

## 禁止事項
- 噂を確定情報の表に入れない。
- 前回ファイルがあるのに差分を取らず全件を書き直さない。差分が主出力である。
- 負傷の内容や私生活に関する当事者発信を、本人の公表範囲を超えて書かない。
- 固有名詞は原語を併記する。
